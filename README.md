### 🚀 Proyecto destacado

#### 🏢 CONVII — Inteligencia Habitacional

Plataforma web SaaS para la **administración inteligente de condominios y comunidades residenciales**.

CONVII busca centralizar y simplificar la gestión de comunidades mediante herramientas para administración de **condominios, torres, unidades, propietarios y residentes**, con una arquitectura moderna orientada a la escalabilidad.

**Stack principal:**

* ⚛️ React + TanStack
* 🎨 Tailwind CSS
* 🟢 NestJS
* 🐘 PostgreSQL
* 🔐 APIs REST
* 🏗️ Arquitectura modular y escalable

> Un proyecto enfocado en convertir procesos administrativos tradicionales en experiencias digitales modernas, simples e inteligentes.
